## The demo has a hard size limit

- Either a slide deck of **at most 7 slides** (title and intro slides count) **or a video of 30 seconds or less**.
- "Projects that exceed these limits will not be eligible for Global Judging."
- It must be hosted externally with a public link that needs no login, and it must be in English.
- Slides must show: team name, member names, the challenge we chose, an image of the project, the user experience, and how NASA and partner data make the solution possible.
- No images, video, or audio of anyone under 18.

## Project page form fields (all required, all in English)

1. Project Name
2. High-Level Project Summary (what we built, how it addresses the challenge, why it matters)
3. Link to Project Demo (the 7 slides or the 30-second video)
4. Link to Final Project (public, no login)
5. Detailed Project Description (what it does, how it works, benefits, goals, tools and languages)
6. Use of Super Intelligence (SI). This is the 2026 guide's name for the AI-use field.
7. NASA Data (specific data and resources used; at least one is needed for Global Award eligibility)
8. Space Agency Partner Data and Other References (every piece of code, text, image, data, and tool we used, including open-source ones)

Then tick two boxes (Terms and Conditions; all work is original and every external resource is listed in References) and press "Submit for Judging".

Images (JPG, PNG, GIF up to 10 MB) can be uploaded to the page. Videos and documents cannot.

## AI ("SI") rules

- AI tools are allowed. The guide says they "should not be used to (come up with your idea of how to solve the challenge)". The choice of story and approach has to be the team's own.
- We must say where and how AI was used.
- AI-generated images and video need a visible watermark.
- AI-generated code and data must say so "in descriptive text and metadata". We do this with a header comment in each generated file and with `docs/AI_USAGE.md`.
- AI-generated content may not use, contain, or modify NASA branding (logos, flags, mission identifiers).
- The SI answer is for data collection and is not shown to judges, but judges see the watermarks and notices inside the project.

## Judging criteria (1 to 5 each, same at local and global level)

| Criterion | What a 5 looks like, in short |
|---|---|
| Impact | Addresses a significant problem, benefits a large audience |
| Creativity | A fresh approach or a meaningful improvement on existing ideas |
| Validity | Scientifically sound, technically feasible, complete, usable |
| Relevance | Directly addresses the challenge; NASA data is a core component, not an add-on |
| Presentation | Clear, well-structured story; judged from the demo and the full project |

## What the challenge asks for

- An **interactive, open-source** application that uses **NISAR** radar data to track and visualize one or more types of surface change at a location we choose.
- Hypothesize the **physical drivers** behind what we see (or do not see).
- Say **which polarizations** highlight the changes.
- Say what **future applications of NISAR** are possible.
- Optional but encouraged: several polarizations, a time series, ancillary data (population, vegetation, optical images, GIS layers), human drivers, personal context, interactive elements such as sliders and web maps.

## Other things the guides ask for

- If we host on a new website, request a FortiGuard Web Filter Classification so judges behind filters can open it: <https://www.fortiguard.com/faq/wfratingsubmit> (Company Name: "N/A").
